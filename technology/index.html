Under the Hood

Technology Behind RetinaAI

A modern full-stack architecture combining computer vision, deep learning and explainability with a production-grade web platform.

Inference Pipeline

1

Fundus Image Processing

Input images are resized, contrast-enhanced (CLAHE) and normalized to standardize lighting across cameras before inference.

2

Deep Learning / CNN

A convolutional neural network (ResNet / EfficientNet family) extracts visual features and classifies the image into five DR stages.

3

Explainable AI

Grad-CAM produces a heatmap from the final convolutional layer, revealing which retinal regions influenced the prediction.

4

FastAPI Backend

A Python FastAPI service exposes POST /predict for real model inference — the React frontend is already wired to swap the mock engine.
